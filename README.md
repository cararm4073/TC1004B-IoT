## Instructions to run on Linux

>[!TIP] Pre-requisites
> Make sure you have [installed XAMPP](https://sourceforge.net/projects/xampp/) or any other similar software
> To access the MySQL Database, it is recommended to first change the port to 3307 or any other port to avoid problems with other programs
> It is recommended to use [DBeaver-ce](https://dbeaver.io/download/) for ease, or any VSC profile with the corresponding extensions set up


>[!NOTE] How to start XAMPP?
> Run the following command in the terminal
> `sudo /opt/lampp/lampp start`
> Enter your sudo or user password, and head over to the **Manage Servers** tab
> Do any configuration you consider important (like changing the port), and start the server


>[!NOTE] How to access the server?
> To access it through the terminal, the vollowing command must be run:
> `sudo /opt/lampp/bin/mysql -u root -P 3307`
> Make sure the port corresponds to the one you have previously set up
